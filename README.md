## “不超售”能验证到什么程度

不超售没法从外部直接验证。拿到手的是一台虚拟机，看不到宿主机上还跑着多少个邻居。能间接判断的是三件事。

**缺货的方向性。** 超售的商业逻辑是把物理机塞满，产能应该充裕、随买随有。DMIT 反着来：洛杉矶 Pro 的 WEE、TINY 和香港 Pro 系列，补货后几小时内基本就没了。这个现象持续了几年，不是某次促销的偶发情况。

**价格。** 不超售意味着单台物理机的可售资源有上限，收入只能靠单价补。同样 1 核 1G 的年付配置，DMIT 的报价明显高于主打性价比的商家。多出来的钱买的是路由和余量，不是 CPU 核心数。

**硬件分级。** 平台分 Next、Stable、LTS 三级，Next 升级到新硬件后，旧硬件下放到 Stable，存量用户被动获得性能提升。洛杉矶已经部署 AMD EPYC 9005，香港和东京计划在 2026 年第二季度跟进。这套机制只有在单机负载被控制住的前提下才好推，否则下放硬件只会让拥堵更严重。这一条是判断，不是官方承诺。

## 流量跑超之后到底怎么处理

这件事比“不超售”三个字更影响日常使用。DMIT 官方文档列了三种超量处理规则，不同套餐对应不同的规则：

1. **超量停机。** 跑满额度后实例被暂停，可以在面板里看超量详情。
2. **超量限速。** 端口被限速，限速后只有 SSH 连接保持可用，其他服务可能受影响。
3. **不限制。** 额度跑超不做处理，但这类套餐的端口速率通常较低，官方举的例子是 LAX.Pro.u 系列。

所以“跑超了只是限速、不会关机”这个说法只对部分套餐成立。公开整理给出的具体数值是：洛杉矶 T1 超量限速 100Mbps，香港和东京 T1 超量限速 50Mbps。另一份整理写成“最高限速 1Gbps”，两个口径冲突，这里按更具体的那个采用。

额度用完之后还有两条路：付费重置流量，费用等于续费价除以计费周期；或者等下个重置日自动恢复。付费重置大多数标准套餐都支持，额外购买流量额度目前只有 sPro 系列可以。

**Pro（Premium）** 走三网 CN2 GIA。洛杉矶 Pro 去程电信 CN2 GIA、联通 AS9929、移动 CMIN2，三网回程 CN2 GIA；香港 Pro 双向 CN2 GIA，移动联通直连。面向国内用户的站点、需要稳定低延迟的远程操作，选这一档。香港 Pro 比洛杉矶贵不少，换来的是物理距离上的延迟优势。

**EB（Eyeball）** 是性价比档。洛杉矶 EB 三网回程 AS9929（联通、电信）+ CMIN2（移动），2025 年初更新后联通回程换成了 AS9929。优化不如 CN2 GIA 彻底，日常建站、跑轻量服务够用，价格大约是 Pro 的一半。东京 EB 已经下架，东京现在只剩 Pro 和 T1。

**T1（Tier 1）** 走国际骨干，不含中国大陆优化。国内访问延迟比前两档高，价格最低，流量给得最厚。只需要国际出口的人买 Pro 是浪费钱：目标用户在海外、做外贸站、跑定时同步任务，T1 完全够。

DMIT 是搬瓦工的上游之一，自营线路更纯粹；搬瓦工的 CN2 GIA 套餐流量更多，价格也相对亲民。追求线路纯粹和不超售选 DMIT，要大流量和更多套餐组合，搬瓦工是另一个方向。

## 下单前要确认的六件事

**1. 默认禁用 root 密码远程登录。** 官方 FAQ 写得很明确：为保证安全，远程 root 密码登录默认关闭，建议用 SSH 密钥。需要走控制台的话，先在面板 Access 标签里改 root 密码，再从 Console 登进去。完全没碰过 Linux 的人，下单前先看一遍密钥连接教程，不然机器开出来连不上。

**2. 退款窗口是 3 天 / 30GB。** 两个条件同时满足才全额退，扣网关手续费。30 天内按剩余价值退。

**3. 换 IP 有规则。** 每 15 天可以免费换一次，其他情况 $5/次；月付订单需要剩余有效期大于 15 天。购买时可以勾 IP Guarantee+，新机 IP 被封免费换一次。

**4. 系统支持两份说法不一致。** 一份整理写“只提供 Linux，暂不支持 Windows”，另一份写“面板重装时可以选 Windows，建议 2GB 内存以上”。以重装页面实际能选的为准，别按攻略下单。

**5. 注册别挂代理。** 用真实网络和接近真实的信息注册，风控会过滤明显虚假的资料，可能直接自动退款。

**6. 缺货是常态，补货要抢。** 洛杉矶 Pro 的 WEE、TINY 和香港 Pro 系列尤其明显。看到有货别犹豫太久，客服不会给你留一台。
